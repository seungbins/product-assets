|---|---|
| 원격 코드 실행(RCE) | 악성 모델/에셋 파일 로드 시 임의 코드 실행 |
| 경로 순회(Path Traversal) | 배치 처리 시 파일 경로 조작으로 임의 파일 접근 |
| 인증/인가 우회 | API 키/세션 관련 우회 |
| 리소스 남용 | 과금·GPU 자원을 비정상적으로 소모시키는 입력 |
| 정보 노출 | 사용자 업로드 콘텐츠·모델의 의도치 않은 노출 |
| 공급망 | 서드파티 의존성/모델 배포 채널 변조 |

### 제출 규칙

- 최초 발견자에게만 보상 (중복 제출은 보상 없음, 단 트리아지 판정 근거는 안내)
